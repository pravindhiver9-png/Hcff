# हमारी चिट फण्ड फैमिली 2.0 — Flutter Starter

यह शुरुआती Flutter प्रोजेक्ट है, पूरा ऐप अभी नहीं है।

## चलाने का तरीका
1. Flutter SDK इंस्टॉल करें।
2. इस फ़ोल्डर में टर्मिनल खोलें।
3. `flutter pub get`
4. `flutter run`

## इस चरण में शामिल
- Green + White Minimal Neomorphism theme
- Light और Dark theme की बुनियाद
- चारों तरफ raised card shadows
- साझा app background asset
- Statement PDF के लिए अलग background asset
- शुरुआती Dashboard layout और छह quick-entry tiles

## Assets
- `assets/images/app_background.png`: Homepage और सभी सामान्य ऐप स्क्रीन; अन्य PDF reports के लिए भी यही asset।
- `assets/images/statement_pdf_background.png`: केवल Statement PDF।

## आगे के चरण
Member management, loan workflows, repayment carry-forward rules, monthly jama, expenses, extra amount, distribution, role-based login, Google Sheets / Apps Script sync, localization, PDF generation और tests अभी जोड़े जाने बाकी हैं।
